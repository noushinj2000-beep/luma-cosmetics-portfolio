# لوما | LUMA

## اجرا
فایل `index.html` را مستقیماً باز کنید یا پوشه را در GitHub Pages منتشر کنید. وابستگی به build step یا سرور وجود ندارد. فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در حالت آفلاین فونت‌های سیستمی جایگزین هستند.

## نسخه نمایشی
این فروشگاه استاتیک و نمایشی است: فهرست و قیمت نمونه‌اند، حساب واقعی، ثبت سفارش و پرداخت ندارد. سبد خرید فقط در مرورگر و در صورت مجازبودن localStorage ذخیره می‌شود.

## تصاویر
تصویر کمپین اصلی در `assets/campaign.webp` قرار می‌گیرد. تا زمان افزودن آن، تصویر `assets/beauty.webp` به‌عنوان جایگزین استفاده می‌شود. تصاویر جانبی در `assets/promo.webp` هستند.
